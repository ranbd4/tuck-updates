# Tuck updates

Release downloads and the update feed for **Tuck**, a private clipboard manager for macOS (Apple silicon, macOS 26+).

- **Download:** see [Releases](https://github.com/ranbd4/tuck-updates/releases). Open the DMG and drag Tuck to Applications.
- **Updates:** Tuck checks `appcast.xml` in this repo once a day. Every update is signed with an EdDSA key, and Tuck refuses any download whose signature doesn't match.

The source code is kept in a separate private repository.
